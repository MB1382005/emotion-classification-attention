Project Overview

This project classifies text into 6 core Ekman emotions (Joy, Sadness, Anger, Fear, Surprise, Disgust) using Google's GoEmotions dataset. It benchmarks LSTM, GRU, and BiLSTM + Bahdanau Attention (initialized with pre-trained GloVe 100d embeddings) against a fine-tuned DistilBERT Transformer trained with the HuggingFace Trainer API.
